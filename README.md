# دوامي

[فتح الموقع](https://pcp-field.github.io/dawami/)

تطبيق عربي بسيط يخبرك مباشرة:

- هل أنت مداوم أو في الإجازة؟
- كم يوم دوام باقي على الإجازة؟
- متى تبدأ الإجازة؟
- متى ترجع إلى الدوام؟

## طريقة الاستخدام

أول مرة فقط:

1. اختر نمط دوامك.
2. حدد أول يوم دوام.
3. حدد وقت بداية ونهاية الدوام.
4. اضغط «احفظ وابدأ».

بعدها يحسب الموقع النمط تلقائيًا لكل الشهور والسنوات.

## الواجهة

الموقع يحتوي على ثلاثة أقسام فقط:

- **اليوم:** حالتك والعداد والمواعيد المهمة.
- **التقويم:** الأصفر دوام والأسود إجازة.
- **الإعدادات:** تغيير النمط والتاريخ والوقت.

يدعم الوضع الداكن والفاتح، العمل على الهاتف، التثبيت كتطبيق PWA، الحفظ المحلي، والتنبيه قبل الدوام.

## البيانات القديمة

تظل البيانات القديمة محفوظة ويقرأ الموقع تلقائيًا من مفاتيح الإصدارات السابقة. لا يحذف الموقع بيانات المستخدم عند التحديث.

## الاختبار والنشر

يشغّل GitHub Actions اختبارات محرك الحساب والواجهة قبل نشر الموقع على GitHub Pages.

## آخر تحديث

الإصدار 6.0: تجربة هاتف بأسلوب Apple/SaaS، تنقّل رجوع محسّن، إضافة اليوم بواجهة عملية، الإجازة القادمة بدقة، وعدّاد أيام دوام الشهر.
