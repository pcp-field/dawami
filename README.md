# دوامي

[فتح التطبيق](https://pcp-field.github.io/dawami/)

«دوامي» تطبيق عربي Mobile First لإدارة جدول الدوام والإجازات. يبدأ بالتقويم مباشرة، ويعرض ملخص الحالة والعدادات في نافذة سفلية عند الضغط على «حالتي».

## أهم المزايا

- أنماط جاهزة: 14/14، 28/14، 7/7، 4/4، 2 نهاري + 2 ليلي + 4 راحة، و5/2.
- دورة مخصصة تُكتب بالعربية، مثل: `نهاري، نهاري، ليلي، ليلي، راحة، راحة، راحة، راحة`.
- إعداد أول مرة من 7 خطوات مع معاينة 60 يومًا.
- تقويم شهري وأسبوعي وقائمة، وسحب للتنقل بين الأشهر.
- تعديل يوم واحد، أكثر من دوام في اليوم، إكسترا دي، ملاحظات، موقع ورقم Job/Hoist.
- تحديد عدة أيام، نسخ ولصق، تعديل جماعي، تراجع، وقفل الجدول.
- إجازات سنوية ومرضية وطارئة وتعويضية وبدون راتب وتدريب ونصف يوم.
- حساب الإجازة القادمة، الرجوع للدوام، أيام الدوام المتبقية وساعات الشهر.
- «أفضل فرصة لإجازة»، مخطط سفر، رؤى الجدول، ومقارنة جدولين محليًا.
- راتب أساسي، إضافي، بدل ليلي وموقع، وتقدير دخل الشهر.
- تصدير ICS وCSV، مشاركة نص أو صورة أسبوعية، وطباعة/PDF من المتصفح.
- نسخ احتياطي JSON مع تحقق وتأكيد قبل الاستبدال.
- عطلات سلطنة عُمان من ملف محلي محدث، مع نسخة محفوظة للعمل دون اتصال.
- وضع داكن وفاتح، لوحات ألوان قابلة للتخصيص، PWA وOffline.

## الخصوصية والبيانات

كل البيانات تبقى على جهاز المستخدم داخل `localStorage`. لا يوجد خادم مدفوع ولا تُرفع الأجور أو الملاحظات إلى أي خدمة. بنية البيانات الحالية تحمل `version: 5`.

عند التحديث يقرأ التطبيق تلقائيًا المفاتيح القديمة:

- `dawami-github-schedule`
- `dawami-github-prefs`
- `dawami-cycle-prefs`
- `dawami-cycle-overrides`

ويحفظ نسخة ترحيل احتياطية قبل التحويل. لا يحذف التطبيق المفاتيح القديمة.

## التشغيل محليًا

المشروع ثابت ومتوافق مع GitHub Pages. شغّل أي خادم ملفات محلي، مثل:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الاختبارات

```bash
node tests.mjs
node smoke-tests.mjs
```

تغطي الاختبارات: 14/14، الدورة المخصصة، السنة الكبيسة، الدوام الليلي عبر منتصف الليل، التعديل الفردي والمتعدد، الإجازات ونصف اليوم، الإحصاءات، سلامة النسخ الاحتياطي، PWA، ووجود عناصر الواجهة المطلوبة.

## ملاحظة التنبيهات

التنبيهات تعمل فقط بعد تفعيلها يدويًا ومنح الإذن. على iOS يجب تثبيت الموقع على الشاشة الرئيسية، وحتى عندها لا يضمن المتصفح تشغيل مؤقتات بعيدة المدى إذا كان التطبيق مغلقًا بالكامل؛ لذلك يعرض «دوامي» هذا القيد بوضوح ولا يدّعي نجاح تنبيه غير مضمون.
