# دوامي — منظم الورديات

[فتح الموقع على GitHub Pages](https://pcp-field.github.io/dawami/)

منظم ورديات عربي يعمل مباشرة في المتصفح.

## المميزات

- تقويم شهري ملون للورديات
- إضافة وتعديل وحذف المناوبات
- تطبيق نمط 4 أيام عمل / 4 أيام راحة
- حساب الساعات والأجر والعمل الإضافي بالريال العُماني
- متابعة الإجازات وأيام الراحة
- وضع داكن وفاتح
- تصدير تقرير CSV
- حفظ تلقائي على الجهاز

## الاستخدام

افتح الموقع، ثم عدّل جدولك. جميع بياناتك تحفظ محليًا داخل متصفحك.

الموقع مبني بـ HTML وCSS وJavaScript بدون خادم أو قاعدة بيانات.
