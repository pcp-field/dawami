# دوامي — مساعد المناوبات الذكي

[فتح التطبيق المنشور](https://pcp-field.github.io/dawami/)

تطبيق عربي احترافي لإدارة المناوبات والإجازات، يعمل مباشرة في المتصفح ويمكن تثبيته كتطبيق PWA. لا يحتاج خادمًا أو اشتراكًا مدفوعًا، وتبقى بيانات المستخدم على جهازه.

## أبرز المزايا

- بطاقة «حالتك الآن» مع عداد حي وموعد الوردية أو الإجازة التالية
- أنماط 14/14 و28/14 و7/7 و4/4 و2 نهاري + 2 ليلي + 4 راحة و5/2
- دورة مخصصة بأي تسلسل عربي تتكرر تلقائيًا
- إعداد أول من سبع خطوات ومعاينة فعلية لأول 60 يومًا
- تقويم شهري وأسبوعي وقائمة، مع السحب على الهاتف
- ورديات نهارية وليلية وإضافية وتدريب وراحة وإجازات ومرضية
- أكثر من وردية في اليوم ودعم الوردية العابرة لمنتصف الليل
- تحديد متعدد ونسخ ولصق وتراجع وقفل للجدول
- إجازات سنوية ومرضية وطارئة وتعويضية وبدون راتب ونصف يوم
- حساب الرصيد المستخدم والمتبقي ودعم الرصيد المرحّل
- «أفضل فرصة لإجازة» لاستخراج أطول راحة بأقل أيام
- «رؤى دوامي» لتحليل ضغط الساعات والورديات والراحة والراتب
- تصدير CSV ونسخة احتياطية JSON قابلة للاستعادة
- وضع داكن وفاتح ودعم RTL والمنطقة الزمنية
- تثبيت PWA وعمل أساسي دون اتصال وتنبيهات بأفضل جهد

## الخصوصية وترحيل البيانات

يستخدم الإصدار الحالي مخزنًا محليًا باسم `dawami-data-v3`. عند أول تشغيل، يقرأ بأمان البيانات القديمة من:

- `dawami-github-schedule`
- `dawami-github-prefs`
- `dawami-cycle-prefs`
- `dawami-cycle-overrides`

ولا يحذفها. كما يحتفظ بنسخة احتياطية محلية قبل الترحيل.

## التطوير والاختبار

المشروع مبني بـ HTML وCSS وJavaScript خالص ومتوافق مع GitHub Pages. يشغّل GitHub Actions قبل النشر:

```bash
node tests.mjs
node smoke-tests.mjs
```

الاختبارات تتحقق من محرك الدورات، الورديات الليلية، الاستثناءات، الإجازات، إحصاءات الساعات، سلامة JavaScript، ربط عناصر الواجهة، وملفات PWA.
